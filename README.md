# Machine Vision-Based Water Bottling Plant for Impurity Detection

## 📋 Project Overview
This project implements a machine vision system to detect impurities in water bottles during bottling and to detect missing caps and labels.

## 🎯 Objectives
- Automated quality control in water bottling
- Real-time impurity detection
- Reduce manual inspection errors
